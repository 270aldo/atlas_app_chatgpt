# @atlas/widgets

Widgets React para ATLAS app en ChatGPT.

## Desarrollo

```bash
pnpm dev     # Servidor en http://localhost:4444
pnpm build   # Generar bundles con hash
pnpm lint    # Ejecutar ESLint
```

## Widgets disponibles

- atlas-dashboard
- atlas-weekly-board
- atlas-session-checkin

## Estilos

- Dark premium, Electric Violet (#7C4DFF), Deep Purple (#512DA8)
- Tipografías: Josefin Sans (headings), Inter (body)
- Tailwind + componentes accesibles
